# PDF Export Lambda Deployment Issue

## Problem
The @sparticuz/chromium package is ~64MB and causes deployment size issues.

## Solution
Use a custom Lambda Layer containing @sparticuz/chromium.

## Current Status
- Lambda Layer created: `arn:aws:lambda:ap-south-1:407800164427:layer:chromium-sparticuz:2`
- Layer contains @sparticuz/chromium package
- exportPdf function configured to use the layer

## Issue
The code needs to import @sparticuz/chromium dynamically from the layer, but esbuild configuration is preventing proper resolution.

## Next Steps
Test if the current deployment works by checking CloudWatch logs for the actual error.

# Server-Side PDF Export Lambda Deployment - Complete Guide

## Problem Statement
The initial deployment failed with error: "Unzipped size must be smaller than 262144000 bytes (250MB)"

The issue was that `@sparticuz/chromium` package (~64MB compressed, ~130MB unzipped) was being included in every Lambda function, causing the deployment package to exceed AWS Lambda's 250MB unzipped size limit.

---

## Solution Overview
1. Use AWS Lambda Layers to provide Chromium binary separately
2. Configure esbuild to bundle functions individually and efficiently
3. Mark @sparticuz/chromium as external so it's loaded from the layer
4. Optimize package patterns to exclude unnecessary files

---

## Step-by-Step Implementation

### Step 1: Install Required Dependencies
```bash
npm install @sparticuz/chromium puppeteer-core
```

**Why these packages:**
- `@sparticuz/chromium`: Provides Chromium binary optimized for Lambda (Brotli compressed)
- `puppeteer-core`: Headless browser automation (doesn't include Chromium binary)

### Step 2: Create PDF Service
**File:** `src/services/pdf.service.ts`

```typescript
import puppeteer, { Browser } from 'puppeteer-core';

export class PdfService {
  private static async getBrowser(): Promise<Browser> {
    const isOffline = process.env.IS_OFFLINE;
    const isLambda = !isOffline && (process.env.AWS_LAMBDA_FUNCTION_VERSION || process.env.AWS_EXECUTION_ENV);

    let executablePath: string;
    let args: string[] = [];

    if (isLambda) {
      console.log('Running in Lambda environment');

      // Use @sparticuz/chromium for Lambda (from Layer)
      try {
        const chromium = await import('@sparticuz/chromium');
        executablePath = await chromium.default.executablePath();
        console.log('Chromium executable path:', executablePath);

        if (!executablePath) {
          throw new Error('Chromium executable path is undefined');
        }

        args = [
          ...chromium.default.args,
          '--disable-dev-shm-usage', // Important for Lambda
          '--single-process',
        ];

        console.log('Chromium args:', args);
      } catch (error) {
        console.error('Error getting Chromium executable path:', error);
        throw error;
      }
    } else {
      console.log('Running in local environment');
      // Local development fallback paths
      const platform = process.platform;
      if (platform === 'darwin') {
        executablePath = '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome';
      } else if (platform === 'win32') {
        executablePath = 'C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe';
      } else {
        executablePath = '/usr/bin/google-chrome';
      }
    }

    console.log('Launching browser with executablePath:', executablePath);

    return puppeteer.launch({
      args,
      defaultViewport: { width: 1920, height: 1080 },
      executablePath,
      headless: true,
    });
  }

  static async generatePdf(html: string, css: string): Promise<Buffer> {
    let browser: Browser | null = null;
    try {
      browser = await this.getBrowser();
      const page = await browser.newPage();

      const fullHtml = `
        <!DOCTYPE html>
        <html>
          <head>
            <meta charset="UTF-8">
            <style>
              *, ::before, ::after {
                box-sizing: border-box;
                border-width: 0;
                border-style: solid;
                border-color: #e5e7eb;
              }
              html, body {
                margin: 0;
                padding: 0;
                -webkit-print-color-adjust: exact;
                print-color-adjust: exact;
              }
              ${css}
            </style>
          </head>
          <body>
            ${html}
          </body>
        </html>
      `;

      await page.setContent(fullHtml, {
        waitUntil: 'networkidle0',
        timeout: 30000
      });

      const pdfBuffer = await page.pdf({
        format: 'Letter',
        printBackground: true,
        displayHeaderFooter: false,
        margin: {
          top: '0px',
          bottom: '0px',
          left: '0px',
          right: '0px'
        },
        preferCSSPageSize: true
      });

      return Buffer.from(pdfBuffer);
    } catch (error) {
      console.error('Error generating PDF:', error);
      throw error;
    } finally {
      if (browser) {
        await browser.close();
      }
    }
  }
}
```

**Key points:**
- Dynamic import of @sparticuz/chromium in Lambda (loaded from layer)
- Fallback to local Chrome for development
- Proper error handling and browser cleanup

### Step 3: Create Export Handler
**File:** `src/handlers/export.ts`

```typescript
import { Request, Response } from 'express';
import serverless from 'serverless-http';
import express from 'express';
import cors from 'cors';
import { PdfService } from '../services/pdf.service';

const app = express();

app.use(cors());
app.use(express.json({ limit: '10mb' }));

app.post('/resumes/export', async (req: Request, res: Response): Promise<void> => {
  try {
    const { html, css } = req.body;

    if (!html) {
      res.status(400).json({ success: false, message: 'HTML content is required' });
      return;
    }

    console.log('Generating PDF...');
    const pdfBuffer = await PdfService.generatePdf(html, css);
    
    console.log('PDF generated successfully, size:', pdfBuffer.length);

    res.setHeader('Content-Type', 'application/pdf');
    res.setHeader('Content-Disposition', 'attachment; filename="resume.pdf"');
    res.send(pdfBuffer);
    
  } catch (error) {
    console.error('Export handler error:', error);
    res.status(500).json({ 
        success: false, 
        message: 'Failed to generate PDF',
        error: error instanceof Error ? error.message : 'Unknown error'
    });
  }
});

export const handler = serverless(app, {
    binary: ['application/pdf']
});
```

### Step 4: Create Lambda Layer for Chromium

```bash
# Create layer directory structure
mkdir -p /tmp/chromium-layer/nodejs/node_modules/@sparticuz

# Copy @sparticuz/chromium to layer
cp -r node_modules/@sparticuz/chromium /tmp/chromium-layer/nodejs/node_modules/@sparticuz/

# Create zip file
cd /tmp/chromium-layer
zip -r chromium-layer.zip nodejs

# Upload to S3 (layer is too large for direct upload)
aws s3 cp chromium-layer.zip s3://serverless-framework-deployments-ap-south-1-164cd7af-37c8/lambda-layers/chromium-layer.zip --profile personal --region ap-south-1

# Publish Lambda Layer
aws lambda publish-layer-version \
  --layer-name chromium-sparticuz \
  --description "Chromium binary for PDF generation (@sparticuz/chromium)" \
  --content S3Bucket=serverless-framework-deployments-ap-south-1-164cd7af-37c8,S3Key=lambda-layers/chromium-layer.zip \
  --compatible-runtimes nodejs22.x \
  --region ap-south-1 \
  --profile personal
```

**Result:** Layer ARN: `arn:aws:lambda:ap-south-1:407800164427:layer:chromium-sparticuz:2`

### Step 5: Configure Serverless Framework
**File:** `serverless.yml`

```yaml
service: resume-builder-api

frameworkVersion: '4'

useDotenv: true

# Configure esbuild for efficient bundling
build:
  esbuild:
    bundle: true
    minify: true
    sourcemap: false
    exclude:
      - 'aws-sdk'
    external:
      - '@sparticuz/chromium'  # Don't bundle, load from layer
    target: node22
    platform: node

provider:
  name: aws
  runtime: nodejs22.x
  region: ap-south-1
  stage: ${opt:stage, 'dev'}
  profile: personal
  memorySize: 1024
  timeout: 30
  # ... other config

functions:
  # ... other functions

  exportPdf:
    handler: src/handlers/export.handler
    memorySize: 3008  # Chromium needs more memory
    timeout: 30
    ephemeralStorageSize: 2048  # Increase /tmp storage for Chromium extraction
    layers:
      - arn:aws:lambda:ap-south-1:407800164427:layer:chromium-sparticuz:2
    events:
      - httpApi:
          path: /resumes/export
          method: POST

plugins:
  - serverless-offline

package:
  individually: true  # Each function gets its own optimized package
  patterns:
    - '!tests/**'
    - '!**/*.test.ts'
    - '!**/*.test.js'
    - '!.git/**'
    - '!.github/**'
    - '!*.md'
    - '!.env*'
```

**Key configurations:**
- `external: ['@sparticuz/chromium']` - Don't bundle chromium, load from layer
- `individually: true` - Each function bundled separately
- `memorySize: 3008` - Chromium needs more memory
- `ephemeralStorageSize: 2048` - More /tmp space for extraction
- `layers` - Attach the Chromium layer

## How It Works

### esbuild Bundling Process
1. **Tree-shaking:** Only includes code actually used
2. **Bundling:** Combines all dependencies into single file
3. **Minification:** Removes whitespace, shortens names
4. **External dependencies:** @sparticuz/chromium loaded from layer at runtime

### Lambda Layer Architecture
```
Lambda Function (1.1 MB)
├── index.js (bundled code)
└── node_modules/
    └── .prisma/client/ (Prisma engine)

Lambda Layer (66 MB, attached separately)
└── /opt/nodejs/node_modules/
    └── @sparticuz/chromium/
        └── bin/
            ├── chromium.br (59MB compressed)
            ├── swiftshader.tar.br
            ├── al2023.tar.br
            └── fonts.tar.br
```

At runtime, Node.js can import from `/opt/nodejs/node_modules/` automatically.

## Key Learnings

1. **Lambda Layers are essential** for large dependencies like Chromium
2. **esbuild's tree-shaking** dramatically reduces package sizes
3. **Individual packaging** prevents all functions from including the same dependencies
4. **External dependencies** must be marked correctly to load from layers
5. **Dynamic imports** work with Lambda Layers when marked as external

## Troubleshooting

### If PDF generation fails:
1. Check CloudWatch logs for the exportPdf function
2. Verify layer is attached: `aws lambda get-function --function-name resume-builder-api-dev-exportPdf`
3. Ensure memory is sufficient (3008 MB recommended)
4. Check /tmp storage (2048 MB for Chromium extraction)

### If deployment fails with size error:
1. Verify @sparticuz/chromium is marked as `external` in esbuild config
2. Check that layer is properly attached to exportPdf function
3. Ensure `individually: true` is set in package config

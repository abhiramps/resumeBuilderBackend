Request Flow
============

1. User uploads resume
        │
        ▼
2. Import handler receives file
        │
        ▼
3. AIParserService.extractResumeData()
        │
        ▼
4. getLLMProvider() ──▶ Returns configured provider
        │
        ▼
5. provider.generateCompletion(messages)
        │
        ▼
6. Provider calls external API
        │
        ▼
7. Response parsed and returned
        │
        ▼
8. Resume created in database

Environment Setup
=================

Development:
  LLM_PROVIDER=ollama
  OLLAMA_API_URL=http://localhost:11434/api/chat
  OLLAMA_MODEL=llama3.2
  
  Benefits: FREE, Private, No API costs

Staging:
  LLM_PROVIDER=openai
  OPENAI_API_KEY=sk-proj-staging-key
  OPENAI_MODEL=gpt-4o-mini
  
  Benefits: Low cost, Reliable, Fast

Production:
  LLM_PROVIDER=openai
  OPENAI_API_KEY=sk-proj-production-key
  OPENAI_MODEL=gpt-4o-mini
  
  Benefits: Best value, Proven reliability


Key Benefits
============

✓ Flexibility      - Switch providers without code changes
✓ Cost Optimization - Use free Ollama for dev, paid for prod
✓ Reliability      - Fallback to alternative providers
✓ Testing          - Easy to test different providers
✓ Extensibility    - Add new providers easily
✓ Type Safety      - Full TypeScript support
✓ Error Handling   - Provider-specific error messages
✓ Health Monitoring - Built-in health checks
